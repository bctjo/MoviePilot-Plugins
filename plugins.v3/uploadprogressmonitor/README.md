# 上传量进度监控（MoviePilot V3）

版本 `0.1.1`，开发预览版。为每位客户独立配置站点、UID 和目标累计上传量，默认每小时整点检查，通过 MP 通知渠道汇总进度。

## 目标如何计算

按站点已经记账的**累计上传量**判断。例如账号目前 2 TiB，目标填写 5 TiB，则累计上传达到 5 TiB 时标记完成。更改目标后按新目标重新判断。

单位按 1024 换算：1 TiB = 1024 GiB，和 NexusPHP 页面中的 TB / GB 口径一致。支持 GiB、TiB、PiB，可填写小数；比较时使用字节数，避免大整数精度丢失。

## 配置

1. 在 MP 站点管理中添加需要监控的站点并配置认证资料。馒头需要 API Key；Audiences / NexusPHP 需要有效 Cookie 和正确的 HTTPS 站点地址。
2. 安装「上传量进度监控」，添加监控任务。每项独立选择站点，填写 UID、目标累计上传量和单位，可填写客户备注。
3. 使用“添加监控任务”增加用户，“移除此任务”删除用户；也可关闭某项“监控此任务”以暂停。最多 100 项，空白任务不参与检查。
4. 同一 UID 可绑定不同站点；同一“站点 + UID”不允许重复，避免冲突目标。
5. 启用插件。默认“每轮推送进度汇总”开启；调试时可关闭推送，仅查看详情。
6. 勾选“保存后立即检查一次”并保存，可在 3 秒后执行一轮。之后按周期检查，默认 cron 为 `0 * * * *`，时区为北京时间。

添加、修改、移除或暂停任务均在保存后生效。扫描中保存配置不打断当前一轮，下一轮使用新配置；关闭插件或重载时会停止当前一轮并保留已经查到的结果。

通知使用 MP 的“站点”消息类型，请确认通知渠道允许该类型。插件仅记录“已提交 MP 通知渠道”，不代表收件端已经收到。

## 每小时通知

每轮检查都会完整汇总以下三组，包括此前已经完成的任务：

- **待完成**：客户备注 / 用户名、站点、UID、当前上传量、目标上传量、进度、剩余量。
- **已完成**：客户备注 / 用户名、站点、UID、当前上传量、目标上传量。
- **查询失败**：站点、UID、失败原因、目标；如有历史成功数据，会明确标注“上次成功”的上传量和时间。

两次均有精确字节数时，另显示较上次检查的变化。累计上传量下降会提示核实，并按当前值重新判断，不保留错误的完成状态。

用户较多时按段落分批通知，不截断任务。未启用 MP 推送时只保存和展示结果；没有有效任务或配置无效时不会发起检查。

## 站点适配

| 站点 | 读取方式 | 凭据来自哪里 |
| --- | --- | --- |
| 馒头 | 官方 `POST /api/member/profile?uid=...`，读取 `memberCount.uploaded` 字节数 | 该任务所选 MP 站点的 API Key |
| Audiences | `userdetails.php?id=...`，支持新版卡片布局及旧版表格布局 | 该任务所选 MP 站点的 Cookie |
| 其它 NexusPHP | 尝试相同的用户详情页模板，支持简体、繁体和英文上传量标签 | 该任务所选 MP 站点的 Cookie |

站点选择器会为馒头、Audiences 和通用 NexusPHP 标注查询方式。其它类型的站点或深度改版的 NexusPHP 不保证适配，不能可靠解析时显示查询失败。

资料页中的导航栏可能显示登录账号自己的流量。新版卡片布局仅读取目标资料容器中的上传量字段，同时核对姓名链接和 UID 字段；旧版表格布局检查目标资料标题后面的上传量。忽略“真实上传量”等不同指标。能够取得精确字节数时优先使用精确值。

NexusPHP 经常只显示四舍五入后的数字。没有精确字节数时，详情标注“约”，并保守判断是否达到目标。例如页面显示约 `5.000 TB`，目标为 5 TiB，因精度不足仍标记待完成并提示“临界值待确认”，避免提前判定服务完成。

单人资料隐藏、Cookie 失效、站点限流或接口错误不会中断其他任务；失败数据不当作 0 或已完成，也不会用登录用户自己的上传量替代。请求不跟随重定向，每项间隔 2 秒，不自动重试失败请求。

## 数据与验证范围

配置只保存任务及站点 ID，API Key / Cookie 复用 MP 站点管理配置。运行数据只保存 UID、站点名、用户名、客户备注、上传量、目标、进度和时间，不保存站点原始响应、HTML、邮箱、IP 或认证资料。详情页按文本渲染用户名和备注。

已核对官方 OpenAPI、NexusPHP 资料页及容量格式化源码，并通过合成数据与离线宿主替身测试。`0.1.1` 已使用用户在本机提供的 Audiences 登录后资料页 HTML 验证新版卡片解析；回归测试使用重建的合成页面，未将原始 HTML 或用户私人资料加入仓库。**尚未完成真实 MoviePilot 加载、Audiences 在线认证请求及通知渠道送达验证。** 需要当前 MoviePilot V3 的 `app.sdk`、宿主调度器和站点 Oper；早期 V3 小版本的兼容性仍需确认。
