# bctjo 的 MoviePilot 插件

面向 **MoviePilot V3** 的个人插件仓库，仅发布本人开发或维护的插件。目前包含：

| 插件 | 版本 | 用途 |
| --- | --- | --- |
| [馒头下级登录提醒](plugins.v3/mteaminvitereminder/README.md) | 0.1.5 | 检查馒头直接下级及手动添加的账号，通过 MP 渠道汇总提醒 |
| [上传量进度监控](plugins.v3/uploadprogressmonitor/README.md) | 0.1.4 | 为每位用户配置站点、UID、初始上传量和任务总量，每小时汇总进度 |

## 安装

在 MP 的插件市场仓库设置中添加以下地址，保留原有官方仓库：

```text
https://github.com/bctjo/MoviePilot-Plugins
```

刷新插件市场，按名称搜索并安装插件。仅适配 V3，V1/V2 索引为空。插件复用 MP 站点管理中的认证资料。

「上传量进度监控」可添加多项独立任务，每项选择站点，填写 UID、初始上传量和任务总量，客户备注可选。例如初始 40 TB、任务 10 TB，目标自动为 50 TB，累计达到 44 TB 时进度为 40%。默认每小时整点检查，汇总待完成、已完成和查询失败的任务。支持馒头与 Audiences，其它 NexusPHP 站点可尝试通用模板；见[使用说明与验证范围](plugins.v3/uploadprogressmonitor/README.md)。

下面为「馒头下级登录提醒」的使用说明。

首次运行开启插件、勾选立即检查，先保持 MP 推送关闭以核对结果。确认后开启“通过 MP 渠道推送给我”，向自己汇总结果。默认北京时间每天 09:00 检查，未浏览超过完整 30 天且等级低于 Extreme User 的账号进入判断；封存、豁免和已到保留期限等情况按[详细说明](plugins.v3/mteaminvitereminder/README.md)处理。

需要关注其他账号时，在“额外提醒账号 UID”中填写 `123456,234567`，多个 UID 用英文逗号分隔。这些账号追加到自动下级名单后面，按 UID 去重，也支持非下级账号；详情标注“直接下级”或“手动添加”。

开启 MP 推送后，每次检查都汇总当次符合条件或无法判断的账号，不受此前通知记录限制；当次没有待提醒账号时不推送。插件仅查询站点资料，通过 MP 渠道通知管理员，由管理员联系相关用户。
